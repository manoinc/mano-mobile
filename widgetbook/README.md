# mano_widgetbook

The component catalogue: every `mano_ui` widget, with knobs, in light and dark, at
phone sizes. It is published inside the handbook at `/widgetbook/`.

```bash
flutter run -d chrome   # from this folder, while iterating
flutter test            # every use case renders; every exported widget is covered
../tools/docs.sh serve  # the whole handbook, catalogue included
```

See `docs/develop/adding-a-component.md`.
